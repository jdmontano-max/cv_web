# CV web de David Alcivar

Requisitos: Node.js 18 o superior.

```bash
npm install
npm run dev      # abre http://localhost:5173
npm run build    # genera la carpeta dist/ para publicar
```

- Edita tus datos en `src/data.js`.
- Coloca tu foto (con tu cara y buena luz) en `public/foto.jpg`. Si no existe, se muestra el monograma "DA".
- Para publicar gratis: sube el proyecto a GitHub e impórtalo en https://vercel.com.
